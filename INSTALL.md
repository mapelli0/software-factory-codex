# Install Software Factory from a Codex chat

Open a local Codex chat on Windows and paste the [installation prompt](README.md#install-from-a-codex-chat). Codex downloads the current release from `main` and runs the installer for your Windows account.

For prerequisites, manual installation, updates and migration of an existing project, see the [current installation guide](https://github.com/mapelli0/software-factory-codex/blob/main/INSTALL.md).

For maintenance of an older per-project installation, its [original setup guide](https://github.com/mapelli0/software-factory-codex/blob/11177bb7ab5787d66a78497dbb38f35ddc8ac4e4/INSTALL.md) is available.
